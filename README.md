# **BreastScan – AI Breast Cancer Prediction App**

BreastScan is an **Android mobile application** that uses **AI (TensorFlow Lite)** to predict the risk of breast cancer using both **health parameters** and **mammogram images**. The app is designed to be fast, simple, and helpful for early risk assessment.

---

## **Features**

* AI-powered prediction using a **tabular ML model**
* Image-based prediction using a **CNN TFLite model**
* Clean and easy-to-use UI
* Works offline for predictions
* Secure login using **Supabase Authentication**
* Supports storing user details and history (optional)

---

## **Tech Stack**

* **Kotlin (Android Studio)**
* **TensorFlow Lite**
* **Supabase (Authentication + Database)**
* **Material Design UI**
